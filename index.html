Official notice

Important message from Finandy

Following an additional assessment of the state of the infrastructure, a decision has been made to discontinue Finandy’s operations and close the project.

The coverage surrounding the previously announced incident affected overall user activity, including the API business, further reducing the economic viability of continued support. The incident itself did not affect the API infrastructure or user funds on connected external exchanges.

Maintaining the API infrastructure in its current form requires significant operating costs. The service’s current revenue no longer makes it possible to provide the necessary infrastructure funding, to meet the obligations associated with its operation, or to support the team of specialists and server capacity.

Finandy’s operations have therefore been permanently discontinued.

We recommend disabling Finandy API keys in the settings of connected exchanges.

Timeline of Finandy’s shutdown

Date What happened
13.04.2026 Support for the Finandy Exchange brokerage program and copy trading was discontinued. Users needed to close active positions on brokerage accounts. The deadline for a full withdrawal of funds was 01.07.2026. API trading continued to operate separately. News link
01.07.2026 The main withdrawal period ended and Finandy’s brokerage infrastructure was shut down. Remaining user withdrawals were processed through a separately deployed Finandy transit wallet.
10.08.2026 Finandy reported a security incident involving the compromise of one of the wallets used to process remaining withdrawals. Withdrawals were suspended. API trading and user funds on connected external exchanges were not affected.
10.09.2026 After a further assessment of the project, a decision was made to discontinue Finandy’s operations entirely. Maintaining the API infrastructure was no longer economically viable due to significant operating costs and a decline in user activity.
10.09.2026 Finandy permanently ceased operations. Withdrawals through Finandy are no longer available. Users are advised to delete Finandy API keys in the settings of connected exchanges.

Aviso oficial

Mensaje importante de Finandy

Tras una evaluación adicional del estado de la infraestructura, se ha tomado la decisión de cesar las operaciones de Finandy y cerrar el proyecto.

El contexto informativo en torno al incidente anunciado anteriormente afectó a la actividad general de los usuarios, incluida la línea de API, lo que redujo aún más la viabilidad económica de su soporte continuado. El incidente en sí no afectó a la infraestructura de API ni a los fondos de los usuarios en los exchanges externos conectados.

El mantenimiento de la infraestructura de API en su formato actual requiere costes operativos significativos. El nivel actual de ingresos del servicio ya no permite financiar la infraestructura de forma adecuada, cumplir las obligaciones asociadas a su funcionamiento ni mantener el equipo de especialistas y la capacidad de servidores.

Por ello, las operaciones de Finandy han cesado de forma definitiva.

Recomendamos desactivar las claves API de Finandy en la configuración de los exchanges conectados.

Cronología del cese de operaciones de Finandy

Fecha Qué ocurrió
13.04.2026 Se interrumpió el soporte del programa de brokerage Finandy Exchange y del copy trading. Los usuarios debían cerrar las posiciones activas en las cuentas de brokerage. El plazo para el retiro completo de fondos se fijó hasta el 01.07.2026. El trading por API siguió funcionando por separado. Enlace a la noticia
01.07.2026 Finalizó el periodo principal de retiros y se detuvo la infraestructura de brokerage de Finandy. Los retiros pendientes se procesaron a través de un monedero de tránsito de Finandy desplegado por separado.
10.08.2026 Finandy informó de un incidente de seguridad relacionado con el compromiso de uno de los monederos utilizados para procesar los retiros restantes. Los retiros se suspendieron. El trading por API y los fondos de los usuarios en exchanges externos conectados no se vieron afectados.
10.09.2026 Tras una evaluación adicional del estado del proyecto, se decidió cesar por completo las operaciones de Finandy. El mantenimiento de la infraestructura de API dejó de ser económicamente viable debido a los significativos costes operativos y a la menor actividad de los usuarios.
10.09.2026 Finandy cesó definitivamente sus operaciones. El retiro de fondos a través de Finandy ya no está disponible. Se recomienda a los usuarios eliminar las claves API de Finandy en la configuración de los exchanges conectados.
